# Start here

> **Translated by AI, waiting for a human review.** Found something odd? Reviewing translations is an open contribution.

These docs walk you through three steps before the code. It takes about ten minutes and saves you from opening the repository without context.

> **In study.** Prumo does not work as a tool yet. It is open research: you can study, discuss and contribute, but not use it on real projects.

## The three steps

1. **Understand the idea.** The problem Prumo wants to solve, the gated-stages hypothesis and the project vocabulary. Read [The idea in 5 minutes](a-ideia.md).
2. **See where it stands.** What exists, what does not work yet and why each decision was made, with sources. Read [Current state](estado-atual.md).
3. **Choose how to take part.** Code, docs, translation, review or questions. Only here do the docs point to the repository. Read [Ways to contribute](formas-de-contribuir.md).

## What about sources?

Every claim about the world has its source at the end of the page; every claim about the project points to the recorded decision (ADR) or the code behind it. All sources used across the project are in [References](../referencias.md) (in Portuguese). A claim without a source is a bug: report it.
